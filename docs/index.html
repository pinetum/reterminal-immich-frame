Your browser cannot talk to serial devices. Use Chrome, Edge or Opera on a desktop — Safari and Firefox have no Web Serial support, and neither does any browser on iOS. This page has to be served over HTTPS to access the serial port.
Before you click. Plug the board in over USB-C. If the installer cannot find it, or the connection drops immediately, put the board into its bootloader by hand: hold Boot, tap Reset, release Boot, then try again.

Choosing Erase device wipes the saved Wi-Fi credentials, Immich API key and album selection along with the firmware. On a first install that is what you want; on an update it is not.

After flashing

  1. Insert a FAT32 microSD card (64 GB or smaller).
  2. The first boot has no configuration, so the device starts its own Wi-Fi access point and shows the details on the panel. Expect to wait about 40 seconds — that is one E Ink full refresh, not a hang.
  3. Join reTerminal-E1004-XXXX (password immich1004), then open http://192.168.4.1 or scan the QR code on screen.
  4. Set Wi-Fi, the Immich server URL and an API key, then pick an album.

The full walkthrough is in the README.

Doing it from a terminal instead

Same image, same result:

esptool.py --chip esp32s3 --port /dev/ttyUSB0 --baud 460800 \
    write_flash -z 0x0 …

Every image, offset and checksum is attached to each release.

Logs come out on GPIO43 (TX) / GPIO44 (RX) at 115200, not USB CDC. Flashing uses ESP Web Tools and happens entirely in your browser — nothing is uploaded anywhere.
